- 한글 완성형 11,172자가 모두 있는 글꼴만 넣었어요. (Gaegu, East Sea Dokdo, Jua, Cute Font 등 2,350자 안팎인 글꼴은 노트에 없는 글자가 생길 수 있어 제외. Asta Sans는 42dot Sans와 모양이 같아 제외)
- 용량을 줄이려고 fontTools로 한글 음절·자모, 영문·숫자, 기본 문장 부호만 남기고 woff로 바꿨어요(원본 3~13MB → 0.4~1.3MB). 글꼴 이름은 바꾸지 않았어요.
