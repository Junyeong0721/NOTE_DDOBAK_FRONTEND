# 목표 글씨체 글꼴

글씨 보정과 연습 모드에서 쓰는 글꼴이에요. 모두 [Google Fonts](https://github.com/google/fonts)의 SIL Open Font License 1.1 글꼴이고, 라이선스 전문은 `OFL/` 폴더에 있어요.

| 파일 | 글꼴 | 원본 |
| --- | --- | --- |
| gowun-dodum.woff | Gowun Dodum (고운돋움) | ofl/gowundodum |
| nanum-pen-script.woff | Nanum Pen Script (나눔손글씨 펜) | ofl/nanumpenscript |
| hi-melody.woff | Hi Melody (하이멜로디) | ofl/himelody |
| gamja-flower.woff | Gamja Flower (감자꽃) | ofl/gamjaflower |
| poor-story.woff | Poor Story (푸어스토리) | ofl/poorstory |

- 한글 완성형 11,172자가 모두 있는 글꼴만 넣었어요. (Gaegu는 2,350자라 제외)
- 용량을 줄이려고 fontTools로 한글 음절·자모, 영문·숫자, 기본 문장 부호만 남기고 woff로 바꿨어요(원본 3~13MB → 0.4~1.3MB). 글꼴 이름은 바꾸지 않았어요.
